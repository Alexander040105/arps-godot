## Overview

This project is a creative reimagining of the classic Rock-Paper-Scissors game expanded to include 15 unique choices: Rock, Paper, Scissors, Fire, Snake, Human, Tree, Wolf, Sponge, Air, Water, Dragon, Devil, Lightning, and Gun.

Players select one of these choices and compete against a computer opponent that randomly generates its pick. The game logic determines the winner based on a complex set of interactions beyond the original three choices, adding strategic depth and variety.

---

## Features

* Classic Rock-Paper-Scissors core gameplay expanded to 15 different elements.
* Randomized computer choice from the full set for unpredictable matches.
* Custom win/lose rules defining which elements defeat others in a layered interaction.
* Simple and intuitive game flow suited for quick play sessions.
* Written in C++ for Godot, making use of Godot’s native module/plugin system
